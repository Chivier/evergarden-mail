Evergarden mail bridge

First sign in to the company Google mailbox in Thunderbird. Download the pairing file from the Evergarden workbench, then import it here. No Google Cloud app is needed.

The bridge only receives Inbox mail. The first run backfills the last 7 days, and mail from before pairing does not trigger new-mail alerts. Keep Thunderbird running; mail and the upload queue stay on this machine and in Evergarden.



Each message is limited to 16 MiB; read larger ones in Thunderbird. After more than 7 days offline, check for missing mail by hand.
