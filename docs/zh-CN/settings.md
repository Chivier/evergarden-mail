# 网页设置

登录后，从侧边栏打开 **设置**。邮箱旁的 **+** 也会进入 **设置 → 邮箱管理**。
设置页支持中英文、深色模式和手机布局。

## 邮箱管理

在邮箱卡片上添加、编辑、启用、停用或移除邮箱。可编辑登录地址、允许的发件人地址、
IMAP/SMTP 主机、端口与 TLS 模式、认证方式、凭据记录、服务提供商和文件夹映射。
别名用于标识归档邮件，创建后不可修改。保存邮箱配置会保留原密码；更换凭据记录会选用
另一份存储的凭据，可能需要重新登录。

密码认证的邮箱，先保存配置，再点击 **设置应用密码**。密码会写入现有的加密凭据库，
不会再次返回浏览器。OAuth 邮箱新增或修改后，先重启，再点击 **连接 OAuth**。
Google OAuth 仍需按[服务商说明](../providers.md)导入您自行注册的应用。

**移除邮箱**需要确认，只删除配置项；已同步邮件、加密凭据、审批历史和服务商上的邮件
都会保留。**停用**还会保留配置项，可随时重新启用。配置修改在重启后生效，重启前已有
操作可能继续完成。

## 使配置生效

邮箱和运行配置保存在 `.local/run/mail-config/` 下的私有文件中，权限为 0600。
在部署目录运行：

```bash
docker compose run --rm migrate
docker compose restart mcp approval-ui mail-ui
```

如果启用了 `scheduler`、`oauth-maintenance` 或 `mfa-autologin`，也需要分别重启。
一次性 worker 在下次运行时读取新配置。迁移命令会先协调数据库中的写入控制状态。
页面将与当前网页进程配置不同的运行设置标为“等待重启后生效”，但无法确认所有服务
是否都已重启。密码和 API 令牌修改立即可用。

网页不持有 Docker socket，重启由服务器管理员操作。修改生产配置前，请备份
`.local/run/mail-config/` 和加密凭据库。

## 运行配置

支持修改登录失败次数上限（默认 15 次）、会话有效期、计划任务时区、日志级别、
草稿审核窗口、服务商登录配置，以及邮件写入和审批策略。权限相关修改需要再次确认。
移入垃圾箱始终需要人工审批，永久删除邮件仍不可用。

设置会经过组合校验，再原子保存，并在启动时覆盖对应的 `EVERGARDEN_*` 环境变量。
它不会重写 `runtime.env` 或 Compose 的 `.env`。部署身份、写入主机和 epoch、数据库连接、
路径、密钥、端口和功能开关仍由服务器管理员配置。若需让某个值重新由环境变量控制，
先停止相关应用，备份 `runtime-settings.json`，从 `values` 对象移除对应字段，再重启。

多页面同时编辑时会检查版本；若其他页面已保存，请刷新后重试。非法配置不会覆盖现有
文件。不要通过重新运行 SOPS 物化脚本来应用网页修改：该脚本会按加密源重新生成邮箱
清单；混合使用时，应先同步加密源中的邮箱配置。

配置编辑由 `EVERGARDEN_MAIL_UI_ACCOUNT_ADMIN_ENABLED` 控制，新安装默认启用。
API 令牌签发另由 `EVERGARDEN_MAIL_UI_API_KEYS_ENABLED` 控制，两个开关都需要在服务器上调整。

## API 令牌

建议每个客户端使用独立令牌，仅勾选需要的权限。有效期可选 30、90、365 天或
**永久不过期**。选择永久令牌后，必须勾选风险确认：令牌泄露后，他人可持续使用其权限，
直到您手动撤销。此次更新不会延长现有令牌。

明文只显示一次，离开 API 令牌标签页或关闭令牌输出后会清除，不写入浏览器存储。
服务器仅保存哈希。**撤销**对有期限和永久令牌都立即生效，无需重启 MCP。
已有令牌如需更换有效期，请创建替代令牌、更新客户端，再撤销旧令牌。

高级 SOPS 部署的 `materialize_secrets.py` 默认生成 365 天有效的兼容令牌。
如需永久令牌，必须同时指定 `--token-ttl-days 0 --acknowledge-no-expiry`，
明确接受令牌泄露后需手动撤销的风险。
